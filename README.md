📌 Overview

This project is an automated test suite for a web application's registration page.
It validates critical workflows such as:

✅ Field validations (username, email, password, confirm password)

✅ Positive test scenarios (valid inputs, successful registration)

✅ Negative test scenarios (invalid emails, short passwords, empty fields)

✅ Error messages and UI feedback

✅ Cross-browser compatibility (if supported)

The project is designed to demonstrate test automation skills for UI testing, form validation, and input handling.
